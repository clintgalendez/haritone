# Getting help

- **Questions and ideas:** open a [GitHub issue](https://github.com/clintgalendez/haritone/issues/new/choose)
  with the feature request template, or comment on an existing one.
- **Bugs:** use the bug report template. Include the Haritone version, the Hytale server
  version, `config.json` (if changed), and the server log lines that start with `[Haritone`.
- **Security problems:** see [SECURITY.md](SECURITY.md). Do not use public issues for these.

Before asking, check the [README troubleshooting section](README.md#troubleshooting) and
[docs/ROADMAP.md](docs/ROADMAP.md). Many "missing" features, such as automatic movement, are
planned or limited by the Hytale API.

Haritone is maintained by volunteers, so responses are best effort.
